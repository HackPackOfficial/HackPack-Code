# DEALR - The Ultimate Automated Card Dealing Robot 🎴🤖

**DEALR** is an automated card-dealing robot with a few tricks up its sleeves! Whether you're playing a classic game or experimenting with custom modes, DEALR takes care of the dealing so you can focus on the fun.

🚀 **Key Features:**
- **Built-in Games:** Play classics like Go Fish, 21, Crazy Eights, War, Hearts, and Rummy.
- **Custom Game Mode:** Choose any number of players and any number of cards per hand.
- **Precision Dealing:** Uses a **color sensor** to detect player tags and deal cards accurately.
- **Need a Hand?:** Just flip a switch and DEALR will make sure you have a **winning hand**.
- **Hackable & Expandable:** Modify firmware to add **custom games and features**.
- **DEALR Hacks:** Extend DEALR’s functionality with community-created modifications.

## 📦 **Getting Started**
- Assemble DEALR with included Arduino Nano (preloaded with DEALR firmware)
- Shuffle included 52-card deck (but feel free to use your own!)
- Place colored **tags at player positions**.
- Select desired game with the four selection buttons
- Play a round!
- Visit crunchlabs.com/DEALR for the **HackPack IDE** as well as Hacks
